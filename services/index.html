这些是我目前为止参与的实际项目：

  • 软体机械爪
    使用 Ecoflex 材料制作了一个带有空腔结构的软体机械爪，结合充气控制和传感器，设计用于物体抓取与感知。未来将使用神经网络对接近物体的形变数据进行识别。

    📍软体机器人、柔性传感器、神经网络

  • 光学仪器控制自动化
    基于c编写控制不同品牌光学仪器的 Python 库，实现了实验平台的一键控制。项目显著减少了操作成本。

    📍仪器控制、自动化、Python

  • 固定翼航模数字识别系统
    基于深度学习模型完成航模上的数字识别系统。该项目结合了图像识别、嵌入式系统与飞行器控制。

    📍YOLOv8、卷积神经网络
